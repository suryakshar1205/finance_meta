# Data Architecture & Documentation

## 1. Overview & Data Source
This directory contains the historical market data used in the quantitative volatility forecasting study:
- **Index:** NIFTY 50 Index (`^NSEI`, National Stock Exchange of India)
- **Primary Data Source:** Yahoo Finance (`yfinance` API) with local fallback disk caching
- **Sampling Frequency:** Daily (Trading Days)
- **Historical Sample Period:** January 4, 2010 to December 30, 2024 (15 Years)
- **Total Valid Daily Observations:** $N = 3,679$

---

## 2. Directory Structure & File Differentiation

```text
data/
├── README.md                          # Data documentation and lineage specification
├── raw/
│   └── nifty50_daily_raw.csv          # Immutable raw downloaded OHLCV data
└── processed/
    └── nifty50_daily_processed.csv    # Cleaned, validated time series with log returns
```

### Distinction Between Raw and Processed Data:
- **`data/raw/nifty50_daily_raw.csv` (RAW DATA):**
  - Downloaded directly from the data provider.
  - Treated as strictly **immutable** to guarantee empirical reproducibility.
  - Contains exact unadjusted and adjusted OHLCV price series.
- **`data/processed/nifty50_daily_processed.csv` (PROCESSED DATA):**
  - Generated by `src/preprocessing.py` after automated data integrity and consistency verification.
  - Contains validated datetime index, logarithmic returns ($r_t = \ln(P_t/P_{t-1})$), and standardized price fields.

## 3. Data Variables & Schema

| Column Name | Data Type | Description |
|---|:---:|---|
| `Date` | `datetime64[ns]` | Trading day index (strictly monotonic ascending) |
| `Open` | `float64` | Session opening index price (INR) |
| `High` | `float64` | Session highest traded index price (INR) |
| `Low` | `float64` | Session lowest traded index price (INR) |
| `Close` | `float64` | Session closing index price (INR) |
| `Adj Close` | `float64` | Dividend/corporate-action adjusted closing price (INR) |
| `Volume` | `int64` | Aggregate traded share volume on NSE |
| `log_return` | `float64` | Daily continuous logarithmic return: $\ln(Close_t / Close_{t-1})$ |

---

## 4. Preprocessing & Data Validation Pipeline

1. **Chronological Ordering:** Verified strictly monotonic ascending datetime index without backwards timestamp jumps.
2. **Duplicate Detection:** Zero duplicate calendar records identified and verified.
3. **Missing Value Handling:** Missing business days correspond to exchange trading holidays (e.g., Diwali, Republic Day). No forward artificial return filling is applied across weekend/holiday gaps; logarithmic returns are computed across consecutive active trading sessions.
4. **Price Consistency Assertions:**
   - $High_t \ge Low_t > 0$
   - $High_t \ge \max(Open_t, Close_t)$
   - $Low_t \le \min(Open_t, Close_t)$
   - All assertions pass with 100% compliance across all 3,679 rows.

---

## 5. Volatility Target Formulation

The forecasting origin is defined at time $t$. To guarantee zero lookahead bias, the target variable is the **forward $k$-day annualized realized volatility** $RV_{t, t+k}$ measured strictly across future trading days $[t+1, t+k]$:

$$RV_{t, t+k} = \sqrt{\sum_{i=1}^k r_{t+i}^2} \times \sqrt{\frac{252}{k}}$$

- **Primary Horizon:** $k = 5$ trading days (1-week forward horizon).
- **Robustness Horizons:** $k \in \{1, 5, 10, 20\}$ trading days.

---

## 6. Data Limitations

1. **Daily Frequency:** The dataset uses daily OHLCV closing snapshots; intraday tick or order book level-2/level-3 data is not included.
2. **Exchange Holidays:** Non-trading days are excluded, reflecting actual continuous market execution.
3. **Single Market Scope:** Represents the Indian large-cap equity market benchmark; cross-market validation is reserved for future research.
